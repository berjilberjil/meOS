# meOS

Personal operating system for one person: finance, health, fitness, tasks, goals,
notes, events and a memory of it all. Native iPhone + Mac apps, one private
backend.

Live backend: **https://meos-api.berjiljacob.workers.dev**

## What is in here

```
apps/
  apple/     Native SwiftUI app (iOS + macOS), generated by XcodeGen
  api/       Headless SvelteKit API on Cloudflare Workers + D1 + R2
mcp/
  diet/      Meal-plan MCP (app bridge, falls back to the cloud vault)
  stuff/     Purchases / ROI MCP (local app bridge only)
supabase/    LEGACY pre-Workers schema. Not used by the running app.
scripts/     Build, install and nightly iOS re-sign helpers
docs/        Architecture notes and historical plans
```

The product is the **native app**. The only web surface is the API's landing
page; there is no web application.

## Run the backend

```bash
cd apps/api
bun install
bunx wrangler login                  # one-time: local bindings use your Cloudflare account
cp .env.example .dev.vars            # local secrets only; never commit
bunx wrangler d1 execute meos --local --file=db/schema.sqlite.sql
bun run dev                          # http://localhost:5173
```

`bun run dev` uses the Cloudflare adapter's platform proxy, so the D1/R2/AI
bindings come from `wrangler.jsonc` just like production. The AI binding is
proxied to Cloudflare, so the login step is required once per machine. Tests, type-check and
production build:

```bash
bun run check
bun run test
bun run build
```

Deployment is `bunx wrangler deploy` from `apps/api` after `bun run build`.
Secrets (`GEMINI_API_KEY`, `MEOS_SECRETS_KEY`, `R2_*`) are set with
`wrangler secret put`; see `apps/api/README.md`.

## Run the Apple app

```bash
cd apps/apple
xcodegen generate
xcodebuild -scheme MeOS-macOS build

# from the repository root:
./scripts/install-apps.sh          # build + install Mac and/or iPhone
```

`xcodegen generate` is required after adding or removing a Swift file — the
`.xcodeproj` is generated and gitignored.

## Status

Working modules: Today, Fitness/Health, Notes, Events, Assistant (Catherine),
Scan, Stuff, Macro, Gallery, Devices, Recycle Bin, Six-Pack Challenge, Fold
read-only banking dashboard, and the backend sync/AI/media stack.

Finance tracking is **not** in the native app today. It was intentionally
replaced by the read-only Fold dashboard; the old Supabase finance tables are
legacy. The Personal Finance expansion is the next major phase — see
`docs/finance-foundation.md`.
